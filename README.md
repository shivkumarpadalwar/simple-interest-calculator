# Simple Interest Calculator Project

This project contains a fully operational frontend web utility designed to calculate simple interest parameters.

## Formula
Interest is computed based on the linear equation:
**SI = (P × R × T) / 100**

- **P:** Principal Sum
- **R:** Annual Percentage Rate
- **T:** Time Delta (Years)

## Technology Architecture
- **HTML5:** Handles layout DOM elements.
- **CSS3:** Presentational UI layer styling.
- **JavaScript (ES6):** Computes form logic and alters output states dynamically.
